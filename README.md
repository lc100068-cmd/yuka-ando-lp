# Yuka｜旅と人生のストーリー

採用済みの縦長漫画7枚を、スマートフォンで順番に読めるLPです。

## 表示と操作

- スマートフォンは画面幅いっぱい、パソコンは目次付きの読みやすい幅で表示。
- 画像をタップすると拡大。上下左右に動かして文字を読めます。「全体表示」で全体に戻り、閉じるボタンまたはEscキーで閉じられます。
- 目次で各ページへ移動。モバイル上部に現在のページと進捗を表示。
- フッターの「漫画の文章を読む」でテキスト版を開けます。
- 画像の内容、削除済みの文章、申込み先は追加・変更していません。

## ファイル

- `index.html`：ページ構成・文章・画像参照
- `styles.css`：スマホ・タブレット・PCのレイアウト
- `app.js`：目次・進捗・拡大表示
- `assets/story-01.webp` 〜 `story-07.webp`：漫画画像
- `assets/story-01-480.webp` 〜 `story-07-480.webp`：小さな画面向けの軽量画像

WebPはPNG原稿から高画質で変換した配信用画像です。画像内の文章・絵柄・縦横比は元のままです。

## ビルド

外部パッケージのインストールは不要です。Node.js 18以降で実行できます。

```sh
npm run build
```

`dist/` に配信用ファイルが出力されます。`dist/` を静的ホスティングの公開ディレクトリに指定してください。ルートのHTML・CSS・JavaScript・assetsをそのまま静的配信することもできます。画像やCSSの参照は相対パスなので、GitHub Pagesのプロジェクト配下でも利用できます。

ローカルで確認する場合：

```sh
python -m http.server 8000 --directory dist
```

## GitHub Pagesで公開する場合

リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、ブランチ `main`、フォルダー `/ (root)` を選択すると、そのまま配信できます。GitHub Pagesの有効化は、このリポジトリの管理画面で別途設定します。

OG画像のURLは `index.html` の `og:image` にあります。別の公開先を使う場合は、その公開先の画像URLに合わせて更新してください。
